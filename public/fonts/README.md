# Embedded resume fonts

Downloaded 2026-10-25 from the official Adobe/Google repositories. Original OFL notices are retained beside each family. No system font files were copied.

- https://github.com/adobe-fonts/source-han-sans/tree/release/OTF/SimplifiedChinese
- https://github.com/adobe-fonts/source-han-serif/tree/release/OTF/SimplifiedChinese
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/roboto
- https://github.com/google/fonts/tree/main/ofl/ebgaramond

The SC faces are complete Simplified Chinese fonts, not subsets made from user content. Latin fonts are variable TTFs. UI and standalone PDF use the same local files. Helvetica Neue, PingFang, Palatino, Arial, Times New Roman and Georgia remain optional system font selections, with fallbacks, and are not bundled.
