# P4.4c Hermes and MCP runbook

CareerAdapt keeps the browser-owned `CareerToolGateway` as the only Career
domain boundary. The MCP endpoint is protocol translation only; it does not
open a `WorkspaceRepository` or receive a browser database handle.

## Local roadshow setup

1. Start CareerAdapt and open an Agent workspace so the browser bridge is
   connected:

   ```text
   pnpm dev
   ```

2. Configure the Hermes companion in its server/local environment. The
   supported contract is:

   ```text
   HERMES_RUNTIME_URL=http://127.0.0.1:<hermes-port>
   HERMES_MODEL=<known-model>
   HERMES_BASE_URL=<openai-compatible-base-url>
   API_SERVER_KEY=<server-only-runtime-secret>
   ```

   `HERMES_RUNTIME_API_KEY` is accepted only at this bootstrap normalization
   boundary. `HERMES_API_KEY` is not a runtime-control or provider fallback and
   should not be configured. Do not put a populated key in `.env.example,
   browser JavaScript, screenshots, logs, or Git. In Electron, the Main-process
   `HermesSupervisor` owns the bundled runtime. In local Web development,
   `pnpm dev` enables the server-side Web Supervisor by default and starts
   Hermes after the browser bridge is ready; set
   `HERMES_WEB_CONTROL_ENABLED=false` to use an externally managed companion
   instead. Production Web remains external/disabled.

   `pnpm dev` is the full-stack development entry point: one launcher lifecycle
   owns one Hermes child and one runtime-control credential. `pnpm dev:next` is
   an explicit UI-only entry point; it starts Next.js without Hermes ownership
   or automatic companion startup.

   The hermetic acceptance gates are:

   ```text
   pnpm hermes:bundle-check
   pnpm hermes:runtime-smoke
   pnpm hermes:integration
   ```

   The former `hermes:preflight` and `hermes:self-test` commands remain
   deprecated compatibility aliases and do not require a manual bridge.

3. Register the HTTP MCP endpoint with Hermes' native MCP client:

   ```text
   hermes mcp add careeradapt --url http://127.0.0.1:3000/api/agent/mcp
   hermes mcp test careeradapt
   ```

   The endpoint is backed by `CareerToolGateway.listContracts()` and
   `CareerToolGateway.execute()`. The browser bridge must be alive before a
   read or write call can complete.

4. Copy the portable Career Skills into Hermes' own skill tree when required:

   ```text
   pnpm hermes:skills
   hermes skills list --source local
   ```

   The sync is explicit and non-destructive by default. Use
   `pnpm hermes:skills -- --force` only when intentionally updating an
   existing CareerAdapt skill copy. A separate `--target <directory>` can be
   used for an isolated Hermes profile.

## Diagnostics

The browser runtime badge exposes only safe status: preferred/active runtime,
Hermes health, MCP connection, and discovered contract count. Server health
also reports provider/model/context/tool-calling status when the companion
provides it. It never returns the API key.

Before a turn, an unavailable Hermes or disconnected MCP boundary remains an
explicit unavailable/recoverable state. After Hermes emits its first event, a
failure remains in that turn and is surfaced without replaying an authoritative
write. There is no silent production Native semantic fallback; Native remains
available only to deterministic/unit/compatibility harnesses. Confirmation
writes and destructive operations stay host-authorized.
