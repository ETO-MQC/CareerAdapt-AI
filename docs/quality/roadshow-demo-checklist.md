# 路演录制检查单

> 本轮完整路演链和真实 Provider 尚未验收。录制前先完成下列检查；不应将局部自动化回归当作全链通过。

## 启动和准备

在项目目录 PowerShell 执行：

```powershell
pnpm hermes:prepare:dev
pnpm dev
```

保持终端运行，打开终端显示的本地地址。首次制备需要本机满足锁定 Hermes 构建环境；后续会核验并复用由锁文件和项目 Skills 决定的开发 runtime。若已配置 `HERMES_RUNTIME_ROOT`，请检查它指向的 runtime 与当前源码一致。旧 runtime 和用户资料不会被清除。

候选模型的独立本地测试可执行 `pnpm dev:mimo`，保留 `pnpm dev` 作为原配置入口。两者可能使用不同端口，浏览器资料按站点来源隔离；候选入口看到空白资料并不表示原资料丢失。MiMo 尚未通过业务资格，暂不推荐用于正式录制。

DeepSeek 独立入口为 `pnpm dev:deepseek`，地址 `http://127.0.0.1:3210`；它与其他入口的浏览器资料隔离，应在该地址重新准备演示资料。真实首页资料确认和新会话回读已通过，但岗位定向完整业务与 Golden Journey 尚未完成，详见 [DeepSeek 资格记录](deepseek-provider-qualification.md)。当前不能仅凭短测决定正式录制模型。

打开 AI 工作台，等待 Agent 状态 Ready；进入「设置 → AI 配置」，检查模型和 Provider。用“你好”发送一条简短消息：若 30 秒内没有正常答复，先检查连接并暂停录制。MiMo 的端点传输冒烟已通过，但业务资格和原 Provider 对照尚未完成。DeepSeek 已通过资料确认及独立岗位匹配短测，完整业务链仍待验收。录制前应在实际演示环境再次试“读取我的资料”“列出岗位”，确认已有报告后问“这段经历对岗位有什么帮助？”，稳定后才请求优化建议；不要展示密钥。

准备 [匿名人物素材](demo/candidate.md) 和 [示例岗位](demo/sample-jd.md)，确认下载目录可用。使用当前已有浏览器资料；切换浏览器或清除站点数据会看不到本地资料。备用材料导入可使用 `tests/fixtures/resume-import/external-aliases.json`：在「我的简历 → 导入已有简历」选择文件，选择本地识别，逐项核对后确认。该 JSON 文件路径已通过定向测试；PDF 完整导入尚未验收。图片与扫描件 OCR 依赖实际配置，不作为默认演示路径。

## 演示顺序

1. 在首页的「人物与版本」创建或选择演示人物；从「从零整理我的经历」输入人物素材，编辑、核对并确认写入个人资料库。
2. 在左侧「个人资料库」检查已确认经历；进入「我的简历」，选择「从个人资料库创建」，打开通用简历和预览。
3. 回到「AI 工作台」，说“我想应聘这个岗位：”并粘贴示例 JD；核对、补充缺失身份信息并保存岗位。
4. 请求岗位匹配；新增经历后选择岗位，查看职业影响和证据。请求岗位简历优化，逐项采用、编辑或忽略，再统一确认。
5. 在「我的简历」打开岗位简历，检查最新版本与预览；选择「下载 PDF」，打开下载文件核对内容。
6. 回到 AI 工作台选择「新任务」，说“继续看我之前那个产品运营岗位”，核对它读取已保存资料、岗位和简历。

预期产物：已保存岗位、一份岗位简历及其新 Revision、可打开且带文字的 PDF。

## 恢复

- 卡住时先点「停止当前任务」，确认写入结果后再重试，避免重复提交。
- AI 读取或生成失败时使用页面的重试入口；必要时刷新并从历史记录返回原会话，检查 Agent Ready 和 Provider 状态。
- 如果仍不能恢复，暂停录制并保留错误现场；不要手工修改数据库。

自动化证据：默认演示资料的正式简历 UI 中，模拟 PDF 导出失败后已保存的 Revision 保持不变，重试成功下载真实 PDF。另在正式工作台和确定性 Provider 下模拟写作 503，验证无新增版本、刷新保留草稿、显式重试及双击只生成一个 Revision。完整岗位简历旅程和其余恢复场景仍需验收。
