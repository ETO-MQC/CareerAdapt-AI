# P4.7b Career Agent Human / Content Review Rubric

This is a small review template for subjective output quality. It is not an
LLM judge, not a regex grader, and not a replacement for deterministic safety,
workflow, Fact Guard, Resume Schema, or artifact tests.

## Review instructions

Review the final assistant output for one sanitized evaluation case. Record
the case ID, reviewer, date, and any evidence references visible in the
product. Do not paste personal profile data, API keys, employer identifiers,
or full user conversations into the review record.

Score each dimension from 0 to 2:

- `0` — absent, materially wrong, unsafe, or unusable;
- `1` — partly correct but needs meaningful revision; and
- `2` — clear, supported, useful, and appropriate for the case.

## General Agent output

| Dimension | 0 | 1 | 2 | Score |
| --- | --- | --- | --- | ---: |
| Factual support | Adds or implies unsupported facts, numbers, ownership, or proficiency | Mostly grounded but has an unclear or weakly supported claim | Claims are traceable to supplied/confirmed evidence and uncertainty is visible |  |
| Relevance | Does not address the user's request or selected capability | Addresses the request with tangential material | Directly addresses the request and selected workflow |  |
| Specificity | Generic advice or wording could apply to anyone | Some concrete detail, but important context is missing | Concrete, case-specific detail without inventing facts |  |
| Natural Chinese | Awkward, repetitive, translated, or hard to read | Understandable with noticeable wording issues | Natural, professional, and easy to scan |  |
| Actionability | Gives no useful next step or asks for the wrong action | Next step exists but is vague or too broad | Clear next step, confirmation boundary, or decision aid |  |
| Unnecessary verbosity | Obscures the result or repeats itself | Some avoidable explanation | Concise for the task while retaining necessary context |  |

## Resume-content additions

Apply these four dimensions when the case produces or reviews resume content.

| Dimension | 0 | 1 | 2 | Score |
| --- | --- | --- | --- | ---: |
| Ownership preservation | Upgrades shared/assisted work or changes responsibility | Ownership is mostly right but wording is ambiguous | Shared, assisted, and independent responsibility remain faithful |  |
| Metric safety | Invents, upgrades, or implies unsupported numbers | Avoids invention but leaves a potentially misleading implication | Uses only supported metrics or explicitly marks missing metrics |  |
| Evidence density | Mostly generic claims with little grounded evidence | Mixes grounded details and generic filler | Each important claim is supported by a useful evidence detail |  |
| Interview defensibility | Likely cannot be explained from the source evidence | Explainable with clarification or edits | A candidate could explain the wording and evidence in an interview |  |

## Review record template

```text

natural Chinese __/2; actionability __/2; unnecessary verbosity __/2.

evidence density __/2; interview defensibility __/2.

What worked:
What needs targeted improvement:
Does this suggest a deterministic safety/workflow bug? yes / no
PII included? must be no
```

Do not average away a zero on factual support, ownership preservation, or
metric safety. A zero there should create a targeted investigation even if the
total score is otherwise high. Any resulting implementation change to a
production Skill, Facade description, tool profile, or `careerRunInstructions`
must rerun the relevant Career Agent Eval subset and the existing downstream
domain/artifact gates.
