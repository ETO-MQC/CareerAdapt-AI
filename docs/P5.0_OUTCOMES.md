# P5.0 成果总结：基础导入、编辑与输出

- 归档日期：2026-10-27。
- 记录区间：2026-10-23～2026-10-26，依据本地 history4.md，按最终交付状态合并重复检查点。
- 产品代码基线：`c3a71a5`；本次归档仅修改文档，不重新打包或变更产品版本号。
- 定位：本阶段成果快照。后续开发的当前入口为 [P5 阶段报告](P5_STAGE_REPORT.md)。

## 1. 阶段结果

本阶段把重点从继续扩展自治求职能力转向导入、手动编辑、排版和输出的可靠性。扫描件识别路由、字段覆盖、三栏编辑器、个性化排版、排序及保存反馈已完成对应范围的实现与验收。基础功能 B0～B6 并未全部完成，真实模型、复杂原件和部分历史 UI 回归仍有待验证。

本文不上传开发日志原文、用户简历、个人联系方式、密钥或本机路径。plan/history 系列和原始参考资料继续按现有规则留在本地；远程读者使用本文、阶段报告及可追踪的专项文档理解当前进度。

## 2. 已交付成果

### AI 配置与运行反馈

- 同一提供商、地址和密钥下，模型切换可在下一轮请求生效；连接配置改变仍走受控重启，保留中断确认及失败恢复。
- 设置页与 AI Agent 页使用实际运行状态更新重启反馈，Ready 后结束进度提示，错误可见。
- Web 开发模式支持受限的本机同源密钥入口，密钥仅驻留服务端内存；生产 Web 不开放此入口。
- 连接测试区分凭据校验与实际生成，测速对鉴权、额度、权限及限流提供脱敏诊断，不把连接成功等同于模型可生成。

### 简历导入与语义一致性

- 扫描 PDF、图片及低质量页面可走模型视觉识别，再进行统一字段映射、来源校验及人工确认；正常文本仍优先提取文本，本地 OCR 为可选路线。
- 独立配置每页识图与每批字段整理预算，默认分别为 480 秒和 600 秒；取消、重试及同批修复预算保留，不改变其他 AI 任务时限。
- 模型边界可转换有来源的纯数值字符串，但不猜测比例、百分比或布尔值；失败详情保留脱敏结构、类型及必要成绩数值，只在当前会话展示。
- 修复混合栏目覆盖、合法校园职务身份、培训分类、排名百分比与位次混淆，以及日期日精度丢失。未映射内容可由用户明确不导入，原始来源仍保留。
- 统一 V2 补齐培训机构、项目、地点与日期等字段；排名百分比、日期、列表输入贯通导入、核对、Repository、编辑、预览和输出。
- 政治面貌沿 `basics.customFields` 保存，必须有来源并经确认，默认在邮箱后展示；不从无关机构名称推断身份，已有用户顺序优先。
- 修复新人物导入后的共享上下文刷新与画布首次适宽监听。

专项证据：[导入字段与参考排版](architecture/resume-import-template-20261024.md)、[输入与字段完善](design/editor-input-presets-drag.md)。

### 简历中心与工作台

- 简历中心形成左侧创建入口与右侧列表，卡片操作、筛选和重命名菜单统一；共享外壳移除重复任务状态栏，任务运行逻辑保持原职责。
- 导入弹窗采用等宽选项与更紧凑尺寸，保留四种识别路线、拖放、目标人物及核对流程。
- 编辑器采用左侧内容、中间 A4、右侧检查器，独立滚动；顶部与浮动工具栏去重，1024px 下保留可达的设置入口。
- 右栏支持指针和键盘调宽、折叠恢复，标签、滚动、草稿、选择和缩放在相关视图切换中保留。
- 应用明暗主题及品牌绿/酒红强调色与简历成品配色分离。

专项证据：[审计与阶段基线](design/ui-ultimate-audit.md)、[交互简化](design/ui-ultimate-phase3.md)、[右栏重构](design/ui-ultimate-phase4.md)。

### 内容管理与排版

- 个人信息支持预设和自定义字段、增删、排序及换行；“显示个人信息标签”输出“手机号：”“邮箱：”等文字标签。
- 板块内嵌条目表单、展开收起、新建、显示隐藏及局部样式；逐条描述输入支持添加与排序，字段格式沿展示配置保存，不建立第二套正文。
- V2 栏目顺序与条目顺序通过原展示配置、Repository 和版本控制保存，七模板尊重用户排序，预览与正式 PDF 共用结果。
- 拖动提供半透明定位及相邻条目滑动，越过中点预览换位，松手一次保存，取消回退，保留键盘操作和减少动态效果偏好。
- 数字输入允许先编辑草稿，在失焦或 Enter 后校验并应用；加减按钮直接应用，滑杆拖动临时预览、释放保存，减少重复写入与分页计算。
- 荣誉输入占满可用宽度，可显式合并为一段或按分号/换行拆为多条，不调用 AI 猜拆语义。
- 提供字体、字号比例、行距、字距、边距、抬头高度、标题与经历布局等设置；可保存跨简历的排版预设，预设不包含人物、正文、照片或栏目顺序。
- 五个可分发字体本地内嵌并附许可；商业系统字体仅作为本机选项。原七模板保留，模板只提供呈现和默认值，不覆盖用户手工排序。

专项证据：[内容侧栏](design/resume-content-sidebar.md)、[字段与侧栏微调](design/resume-sidebar-polish.md)、[精调与性能](design/ui-ultimate-phase4-tuning.md)、[个性化收尾](design/editor-reference-refinement.md)。

### 照片、打印和 PDF

- 当前分支支持本地照片上传、更换、显示隐藏和移除，图片校验压缩后随分支保存，不自动反写资料库；导入照片保留来源和确认。
- 照片不改变姓名、求职意向与联系方式的全文居中；无照片时联系方式默认整体居中，显式用户设置仍生效。
- 抬头高度作用于姓名与联系信息组成的头部，按实际内容避免裁切。
- 六个支持照片的模板共享头部输出，ATS 模板禁用照片并说明。测量、PDF 与打印等图片解码完成，损坏图片明确失败。
- 修复浏览器打印仅首屏、custom 正文投影、跨页尾部内容与部分导出兼容问题；正式 PDF 保持快照、哈希和完整性校验。

专项证据：[编辑器冻结验收](design/resume-editor-closure.md)、[个性化收尾](design/editor-reference-refinement.md)。

### 保存可靠性收尾

- 顶栏显示已保存/未保存，日常保存不再依赖悬浮成功提示。
- 修复荣誉已入库但扩展字段草稿未清导致永久“未保存”；相同内容的保存也返回成功确认。
- 共用经历及规范条目表单区分保存成功、等待事实确认和失败；失败保留输入、允许重试。
- 旧请求完成不会清除保存期间的新输入；基本信息保存不会擦除其他文本草稿，即时文本保存读取本次值，自我评价刷新回读已验证。

专项证据：[保存反馈修复](design/editor-save-acknowledgement.md)。

RAG、embedding/reranker 和免费模型只形成过调研建议，没有在本阶段新增接入或认证；后续必须重新评估，不沿用过时目录结论。
