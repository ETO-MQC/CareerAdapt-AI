## 数据流与状态

资料：当前用户消息 → Hermes 原 facade → 原 capture 服务 → ImportedResumeDraft 候选及原文 → Host 绑定 guided_profile_intake/collect_experience/clarifying → 原候选卡编辑/采用/忽略 → 原最终审核与显式确认入口 → 原 Repository/CAS。候选动作只更新草稿，不能等同正式保存。

岗位：当前 JD → 原 parse/graph → JobTargetSnapshot → 会话 knownSlots/selectedEntities → 当前目标只读核对。临时分析不创建 JobDescription、JobListing 或正式岗位草稿；明确保存继续原确认流程。用户可重新提供修订后的 JD；本轮没有新增逐条编辑临时要求的控件，也没有把只读核对声明为已完成业务确认。保存岗位由 JobsWorkspace 明确选择，URL 携带 jobId；目标切换清除旧工作状态。
