## 独立跟踪 Runtime Readiness

关闭“跨进程 Key 恢复证据缺失”这一子项。独立问题 **R2-RDY-01** 的最终观测为 degraded、reasonCode=hermes_companion_unreachable、providerReady=false、careerMcpReady=true、applyStatus=idle。它不能等同于密钥丢失，具体根因尚未证明。

对于不依赖真实 Runtime READY 的诊断状态解析、错误消息映射、工具事件展示与失败态测试，可以使用现有契约和合成夹具独立推进。实际 Hermes 会话、真实工具执行和模型切换的完整运行验收仍需对应的真实环境，不能由模拟结果替代。

Readiness 的具体网络、控制鉴权、进程或工具注册根因，须由对应运行证据确定；仅一个 unreachable 原因码不足以进一步断言。后续若选择调查该问题，应指定单一检查点和停止条件，不重跑全部 R1。
