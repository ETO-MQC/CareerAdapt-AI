## 4. 第四类负向证据的现有能力与限制

| 所需契约 | 当前实际能力 | 仍不足之处 |
| --- | --- | --- |
| 明确否认 | ClarificationAnswerRecord 有 rejected，分类器有 none；Writer上下文有negativeUserDeclarations | 这些是任务内答案/改写保护，不是确认后的通用负向能力事实；不能把任一拒绝自动解释成不具备能力 |
| 具体岗位要求 | 问题/ConfirmableClaim携带requirementIds，答案通过questionId关联 | 需要统一冻结岗位/要求版本及否认的具体能力范围，不能脱离原问题泛化 |

| 时间范围 | resolvedAt/consumedAt记录回答事件时间 | 没有负向能力的有效起止时间/适用范围，回答时间不等于能力持续不存在 |
| 后续修正 | answerRevision、answerRevisionHash、重新生成/问题计划更新；最新记录替换同questionId旧记录 | 没有统一负向声明supersedes/retracts、适用范围与确认历史契约；不声称系统任何地方都没有历史，只是当前Fit无可靠负向闭环 |
| 明确确认 | 既有Claim确认授权当前材料中的正向事实/改动 | 未形成对上述负向能力范围和有效期的独立明确确认，不应复用正向确认枚举强行扩义 |
