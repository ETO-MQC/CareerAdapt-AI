## 双栏的技术验收契约

- 布局同级chat/divider/artifact；不以portal/fixed/backdrop覆盖chat。
- 容器≥所需宽度时chat≥420px、artifact≥320px，默认约60:40；宽度不足先折导航，再允许用户折产物，保留恢复入口。比例状态只属于布局，不写入Career事实库。
- Pointer capture + keyboard Left/Right/Home/End；aria orientation/min/max/current；主题/路由/resize后不溢出；关闭恢复宽度。
- chat、artifact独立滚动，composer正常流且始终可操作；不自动抢用户上翻位置；未完成时不显示完成态。
- 展示DTO关联session/task/artifact/revision；换session/新task/晚到/取消/失败不串内容；先写合成事件契约测试，再用现Runtime事件适配。
- Artifact边界错误只回退右栏；对话运行、发送/停止和已有内容继续可用。未知状态不得静默当成功。
- 不在UI层签发可信确认或使用`confirmed:true`绕过现门禁；未经确认的建议不得进入预览/PDF。

## 主题与简历输出保护

Host全局外观 → 局部Career语义 → Product组件；Resume独立--resume-*。禁止全局font!important、paper overlay、通配filter/zoom进入A4区域。正式变更若触碰预览同DOM样式，需同snapshot的浅/深/system、100%/高缩放、A4字体/内容/分页、print与PDF一致性证据。不得改变Resume Schema v2/Fact Guard/Repository/ResumeDocument持久化规则。
