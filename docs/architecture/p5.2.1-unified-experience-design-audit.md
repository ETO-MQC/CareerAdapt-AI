## 6. 四种视觉责任与风险

1. **CareerAdapt 品牌**：绿灰层级、克制操作、密度和职业内容语言；可贡献经审查的 Host palette，但当前未安装主题。
2. **Hermes Host**：窗口、全局模式/主题/字体、会话/模型/工具状态、全局设置与权限。公共 SDK 不足的 chrome 改造先做契约评估，不能借私有 import 强行实现。
3. **Career 业务 UI**：限定根容器的语义令牌、Product 组件、Profile/Jobs/Applications/Studio 各自布局。不导入 Repository 到纯展示包。
4. **简历模板**：ResumeDocument 派生、--resume-*、snapshot HTML/PDF，保持白纸和自己的字体/字号/分页；不继承 --ca-* 字体，不给屏幕 A4 注入 Host paper/filter/zoom。

现有 PDF 独立 snapshot HTML 与屏幕同 DOM 预览是两个不同边界：前者不会自动收集 Host styles，后者仍可能受全局 CSS 污染。下一阶段主题回归要同时验证，不声称本轮已测 PDF。正式 Preview/PDF 内容不得包含未确认事实。
