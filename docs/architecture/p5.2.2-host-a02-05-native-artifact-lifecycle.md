## Host Adapter 与数据职责

实现位于 `poc/host-a01/artifact-model.ts`、`artifacts.tsx`、`artifacts.css` 及 `scripts/p522-host-a02-05-patches.mjs`。现有 `scripts/p522-host-a01-renderer.mjs` 增加显式 `--artifacts` 组合选项。

Host ID 为 JSON tuple `[profile, storedSessionId, exactReferenceValue]`，避免跨会话/profile 串数据。它仍是引用身份，不是 inode 或内容哈希身份；不同大小写/路径拼写可能是不同引用。

每次来源保留 Message ID/定位、Tool Call ID、最近前置 user Message ID/轮次、时间及原生写入证据。这个关联能回答“哪个会话、哪条消息和哪一用户轮次产生”，没有虚构后端 Task ID。压缩、rewind 或历史重写后的不可变关联未认证。

适配层排除工具调用参数中的拟写路径、用户附件及外部 URL。Windows 盘符路径仅通过结构化 `files_modified` 结果补足原生解析缺口。成功写入要求工具结果无 error 且路径出现在 `files_modified`。普通 assistant 路径只显示“待核实引用”。

状态边界：

| 状态 | 依据与本轮证据 |
|---|---|
| REFERENCE | 原生引用，不能证明已生成；L1 覆盖 |
| RUNNING / STREAMING | 当前 Session 原生 busy/awaiting/pending 观察；适配测试通过，完整真实生命周期未验 |
| COMPLETED | 产品文案为“文件写入已确认”；来自原生工具结果，真实文件与正文核验通过；不表示整个任务完成 |
| FAILED | 原生工具 error 或当前轮次助手错误；L1/L2 失败及 DB reopen 通过，Electron 失败恢复未验 |
| CANCELLED | 适配层状态转换测试通过；尚无生产原生取消事件映射，不能宣称产品闭环 |
| UNKNOWN | 读取 A-02-04 原生 journal/当前轮次错误，优先于完成；不触发重发。新增 Electron 故障恢复未验 |

同路径更新保留来源消息 occurrence，真实更新合并为一个条目。**Occurrence 不是版本快照**。原生没有旧文件字节历史，显式覆盖后只能预览当前文件。未添加 Artifact 删除/恢复按钮，避免暗示不存在的协议。

历史权威继续是 Hermes `state.db`；文件内容继续保存在工作目录。没有新增 Dexie 表或第二个 Artifact 数据库。确定性测试使用独立 native SessionDB fixture，不是生产存储。
