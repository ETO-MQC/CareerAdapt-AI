# 导入、编辑与参考式模板：2026-10-24

## 范围与证据

用户将模板调研纳入本轮开发，指定比较扫描原件与软件导出，增加类似原件的模板并补齐字段和编辑框。两份原件仅在本地读取：扫描 PDF 1 页、无文本层、8 个图像；导出 PDF 1 页、1089 个可提取文本字符。个人文件、页面渲染和完整正文不写入本报告或测试，不发送到外部模型。

| 观察 | 判断 | 本轮处理 |
|---|---|---|
| 培训被归入“其他内容”，起止时间缺失 | 原 other 结构无日期字段；AI 日期规范化也只接受年/年月，年月日会被隔离；展示器另会截掉日 | V2 新增 training；贯通 AI 草稿、字段目录、适配、确认、存储、编辑、显示与导出。保留日期精度，非法日期/无来源的月日不接收 |
| 排名前百分比被显示为位次 | rankPosition 与百分比不是同一事实 | education 新增 rankPercent（0 < 值 <= 100）；有明确百分比来源时纠正误填位次，其他数字不能冒充百分比 |
| 技能栏目没有独立专业技能 | 原合并栏列的是证书；实际工具能力在自评中，尚不能认定原文被删除 | 提示 AI 扫描全文明确技能声明，保留原段落并给技能条目附同源证据；不从认证推断熟练度、不凭空补技能 |
| 部门独占行、职务重复、缺中间字段时日期位置不稳定 | 展示规则问题，不能改业务字段来迁就模板 | 部门位置可选择跟随模板/同行/独立行，进入展示配置及导出快照；重复标题不重复打印，日期固定右侧列 |
| 技能无类别时内容很窄，熟练度可能看似归属于整个技能组 | 无标签时仍占类别窄列；预览合并技能而测量逐项渲染 | 无类别使用整行；每个技能单独保留 ID、熟练度和说明，测量与正式渲染一致；自定义行保留 |
| 新人物导入后曾无法预览 | Repository 已切换人物，但共享前端上下文未刷新 | 打开导入分支前 refetch 工作区，不跳过人物与分支匹配校验 |
| 窄窗口纸张裁切 | 适合宽度 effect 首次运行时未挂载画布，导入/切换模式后没有重新绑定 | 分支与模式变化重新建立 ResizeObserver，手动缩放仍由用户控制 |

## 统一结构与可编辑性

- 保留 Resume Schema v2，字段目录版本为 v2.2.0。新增 training 是 V2 的增量条目类型，无新 Dexie 表，无破坏性迁移；旧 V2 数据仍可读。
- 培训字段：institution、title、location、startDate、endDate、current、description、highlights、customFields。资料库的兼容事实投影可仍为 other，但正式 structuredFacts/structuredContentItems 保持 training，不由兼容投影反推结构。
- GPA、满分、位次、总人数、百分比、荣誉和部门在既有经历编辑面板上提供对应控件；培训使用字段目录驱动的编辑表单。年月日、年月和年份均可编辑，不通过 month 控件把原值显示为空。
- 编辑仍经过 Repository、Fact Guard、版本检查与人工确认；手改新事实仍需选择仅保存在简历或明确同步，不隐式改写资料库。
- 展示标题覆盖可作用于规范栏目，包括培训；标题只改变展示配置。自定义栏目原有业务结构保持。
- 导入草稿、AI 输出和正式业务对象仍是不同阶段的严格契约，但字段语义相同；新字段同步补到 AI draft Schema，不能只改 Domain 而让模型回包再次失败。

## 新模板：校园浅底

注册 ID `campus-reference`，保留已有六个模板、旧 ID 和默认模板。采用原件的居中姓名、浅灰蓝栏目条、深色细边、教育优先、机构/职位/日期三段式标题、紧凑正文与末尾自评。字体使用已有本机宋体/衬线回退，不下载字体，不添加依赖。

技能、证书和语言在视觉上共用“技能与证书”标题，各自保留独立 V2 类型、栏目容器、条目 ID 和渲染 coverage 标识，不生成第二套模板 JSON。单项熟练度不传播到别的技能。字段较长可以换行，不靠裁切或删字维持一行。

照片自动提取、政治面貌专用编辑字段及更多新模板不在本轮实现中；本模板不是对商业网站源码的移植，也不宣称像素级复制。真实用户 PDF 已确认事实不会被后台批量迁移；旧导入丢失的日期应从原件重新导入核对，不能从残缺导出推测恢复。
