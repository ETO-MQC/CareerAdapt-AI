# P4.3d.2 手工冒烟脚本

在桌面浏览器中打开 Agent Workspace。每一步都使用匿名资料；不要粘贴真实姓名、电话、邮箱或私人简历。

## 1. 新鲜岗位定制

1. 点击“生成岗位定制简历”。
2. 选择当前 Profile、通用简历和目标岗位；按提示回答澄清问题。
3. 打开“产物”，逐项执行“采用”“编辑后采用”和“忽略”。确认每项状态即时更新。
4. 在桌面宽屏检查产物面板：打开分栏、收起，再展开；窗口变窄时检查浮层能关闭并恢复。
5. 当所有修改核对完成时，确认最终应用。
6. 打开新 Job Resume 编辑器，进入页面设置，点击“下载 PDF”。确认文件可打开且正文可读。

## 2. 旧 Session 迁移

用测试环境提供的匿名 legacy Session 打开 AI Workspace，确认：旧的大量问题列表不显示为当前问题，过期确认不显示，旧的运行中 Tool Activity 已结束。流程应从重新分析或生成方案继续；刷新后不应再次显示迁移提示。完成当前 Diff 核对、最终应用和 PDF 下载。

## 3. 从资料库创建简历

点击“从资料库组装简历”，选择目标方向和已确认事实，检查计划后确认创建。确认出现独立通用简历和 Revision，打开编辑器并下载 PDF；Profile 原内容不应被改写。

## 4. 分析岗位匹配度

点击“分析岗位匹配度”，选择 Profile、Resume 和目标岗位。确认结果显示为“岗位匹配分析/匹配概览”，不会创建定制 Session、修改简历或出现 Apply 确认。

## 5. 检查并导出

点击“检查并导出简历”，选择一份 Resume。打开“PDF 导出预览”，进入原功能页并下载 PDF。确认原 Resume 的内容和 Revision 没有增加或改变；该流程只检查并导出，不承诺自动修复。

## 任一步失败时收集

请同时保存：

- 失败位置截图；
- “导出对话”得到的 conversation JSON；
- 当前 Session ID；
- 页面上可见的完整错误文字；
- 浏览器 Console 错误；
- 如果已生成，附上生成的 PDF 文件。
