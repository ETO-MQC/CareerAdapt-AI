# Bespree Reference Specification

## 学习重点

1. 全局顶部栏与简历级工作栏分层。
2. 编辑、AI助手、样式三种模式。
3. 编辑模式：栏目导航 + 当前栏目字段表单 + A4预览。
4. 一次只显示当前栏目，不把全部表单纵向铺开。
5. 样式模式：A4主画布 + 右侧窄检查器。
6. 模板、颜色、字体、页面使用Tab切换。
7. 质量检查先摘要分组，再按需展开问题详情。
8. 高频操作直接可见，低频操作进入更多菜单。
9. 保存状态、撤销、重做、缩放和导出位置稳定。
10. 首页以简历列表为主，卡片仅露出少量高频操作。

## CareerAdapt应保留的差异化

- 结构化字段编辑。
- A4画布与左侧字段双向定位。
- 高频文字的安全原位编辑。
- 栏目级AI优化。
- 整体岗位优化、事实缺口和岗位匹配。
- Fact Guard。
- ResumeRevision。
- 通用简历与岗位简历隔离。
- 多岗位版本和求职工作流。

## 不得复制

- Bespree名称和Logo。
- 原始文案。
- 精确颜色。
- 模板资产。
- 图标资产。
- HTML、CSS或JavaScript源码。
- 一比一视觉复刻。

## 推荐目标布局

### 编辑模式
- 栏目导航：大屏160–220px，中屏48–56px图标栏。
- 字段检查器：大屏400–560px，中屏340–400px。
- A4画布：剩余宽度。
- 三个区域独立局部滚动。

### AI模式
- 左侧AI导航和建议区。
- 右侧继续显示A4画布。
- 全局聊天为次级能力。
- 栏目级AI为高频入口。

### 样式模式
- A4画布为主。
- 右侧检查器320–360px。
- Tabs：模板、颜色、字体、页面。

## Codex验收问题

- 主任务能否在5秒内识别？
- 编辑模式是否只显示当前栏目？
- 手工编辑与AI优化是否清楚分离？
- 左侧字段与A4是否双向定位？
- 高频字段是否可快速修改？
- 低频操作是否收进更多菜单？
- 1366×768是否可用？
- 切换模式是否保留选择、滚动、缩放和草稿？
- AI接受前是否继续经过Fact Guard？
