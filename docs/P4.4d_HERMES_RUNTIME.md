## Preflight and setup

Run these commands in the Hermes environment before a real-provider rehearsal:

```text
hermes --version
hermes doctor
hermes config check
hermes model
hermes mcp list
hermes skills list --source local
```

`hermes model` is the interactive provider/model setup path. The operator must
choose the existing CareerAdapt-compatible OpenAI endpoint and model there, or
provide the server-only `HERMES_BASE_URL`, `HERMES_MODEL`, and
`HERMES_API_KEY` environment values. When the Hermes-specific values are
empty, the server preflight may reuse `AI_BASE_URL`, `AI_MODEL`, and
`AI_API_KEY`; none of these values are sent to browser code.

The five portable skills are synchronized with:

```text
pnpm hermes:skills -- --force
```

The `careeradapt` MCP server must point to the running app's
`/api/agent/mcp` endpoint. The browser-owned `CareerAdaptMcpBridgeClient`
registers the existing `CareerToolGateway`; the server route never receives a
`WorkspaceRepository` or an IndexedDB handle.

```ts
type RuntimeHealth = {
  runtimeId: string;
  runtimeAvailable: boolean;
  providerConfigured: boolean;
  providerReachable: boolean;
  model?: string;
  contextWindow?: number;
  toolCallingAvailable: boolean;
  mcpConnected: boolean;
  mcpToolCount: number;
  careerSkillsLoaded: boolean;
  lastCheckedAt: string;
  safeErrorCode?: string;
};
```

Roadshow readiness is exactly:

```text
runtimeAvailable && providerReachable && mcpConnected && careerSkillsLoaded
```

The model and tool-calling fields remain visible diagnostics. They do not turn
an unavailable provider into a false positive.

## Session and data boundary

Every Hermes turn carries the immutable binding:

```text
personId
profileId
profileVersionNumber
profileRevision
agentSessionId
```

`AgentSession` is the authority. Page context is checked for mismatch but may
not replace a persisted session binding. `CareerToolGateway` verifies the
binding against the browser-owned `WorkspaceRepository` before executing a
tool, filters list results to the fixed person/profile, and rejects stale,
missing, archived, trashed, or cross-profile inputs. The server-side MCP and
Hermes routes only pass sanitized metadata and never perform Repository writes.

The MCP JSON-RPC route requires the binding in the call metadata. A Hermes MCP
configuration must preserve the `careerSessionBinding` metadata (or the
`careeradapt/sessionBinding` alias) on every tool call. If a client cannot
preserve it, the gateway fails closed with
`career_session_binding_required`; it must not silently follow the global
person selector.

## Fallback and recovery

- If Hermes fails before its first runtime event, `AgentRuntimeRouter` falls
  back to Native and annotates the turn with `fallbackUsed`.
- After the first Hermes event, the runtime does not switch mid-turn and does
  not replay a write in Native.
- Session-not-found opens a new Hermes session.
- Read-only transient failures receive one bounded retry.
- Stale revisions trigger dependency rereads and a re-plan hint; writes are
  never automatically replayed.
- Not-found failures refresh tool discovery and return a concise re-plan hint.
- Validation, confirmation, provider timeout, and MCP transient failures keep
  the error code/retry hint visible without inventing a result.

Turn telemetry records total latency, first-token latency when observed, tool
and MCP bridge latency, autonomous recovery count, structured-output validity
when supplied by the runtime, tailoring tool latency, PDF export tool latency,
and fallback status.

## Roadshow checklist

Set `ROADSHOW_AGENT_MODE=true` only for the rehearsal build. The compact
workspace badge then exposes a checklist for runtime, provider/model, Career
MCP, skills, resume preview, and PDF export. Normal users continue to see the
small status badge only.

The release gate still requires a headed Playwright run against a configured
Hermes provider and six real workflows. Until that run produces saved
artifacts, previews, PDFs, and isolation/recovery evidence, the answers for
real Hermes and roadshow readiness remain **NO**.
